# Lapak Kampus – Katalog Produk (React + Vite)

## Menjalankan
    npm install
    npm run dev

## Ganti identitas
Edit `src/data/profile.js` (nama, NIM, prodi, kampus).

## Publikasi
    npm run build
Upload isi folder `dist/` ke hosting pribadi (Netlify, Vercel, GitHub Pages, atau hosting kampus).
